# D1BG's laptop dotfiles
- everything in `config` should be pasted in `~/.config`
- everything in `local` should be pasted in `~/.local`
- `zshrc` should replace `~/.zshrc` (Oh My Zsh is required for everything to work semi-propperly)
- `etc` contains `cmdline.d` (useful for UKIs), `paru.conf` with my own repo and `udev` rules for my laptop
